# Netflix Data Analysis

## 📌 Objective
Analyze Netflix dataset to identify trends and patterns.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📊 Key Insights
- Movies dominate Netflix content
- Content increased rapidly after 2015
- Most content comes from US and India
- TV-MA and TV-14 are common ratings
